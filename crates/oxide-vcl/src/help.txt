oxide-vcl {version} (Oxide VCL), built {date}
Schedules VCL source into PlayStation 2 vector unit assembly.

usage: oxide-vcl [options] [inputfile]

Reads <inputfile>, or standard input when it is absent, and writes the
assembly to standard output unless -o is given. Options come before the input
file, and a value follows its option letter directly: -ofile.vsm, not
-o file.vsm.

output:
  -o<file>       write the assembly to <file>
  -j<file>       also write an assembler header of the program's labels to <file>
  -m[<address>]  wrap the code in a DMA/MPG packet loaded at <address> (default 0)
  -c             emit the source lines as comments
  -s             emit symbolic register names, skipping register assignment
  -f             omit .align directives
  -e             never set the [E] bit (--exitm without an argument does this for one exit)
  -u<name>       prefix generated labels with <name> instead of the file name
  -U             make all labels except .global ones unique

input:
  -n             new syntax mode (like .syntax new)
  -G             run the C preprocessor first (gcc -P -E -C -x assembler-with-cpp)
  -g             run gasp first, for macros and source line information (gasp -p -s -c ';')
  -g+            run gasp with its alternate syntax (gasp -p -a -s -c ';')
  -I<dir>        pass an include directory to the preprocessors
  -W             skip the preprocessors
  -K             keep the preprocessors' temporary files

code generation:
  -L             schedule loops as straight-line code
  -d             plain in-order code generation only; implies -L
  -C             disable the code size reduction pass
  -M             timid (conservative) memory access mode (assumes loads/stores may alias)

mode:
  --mode=vcl     generate the code vcl 1.4beta7 generates (the default); exit
                 status 255 on failure
  --mode=oxide   enable oxide-vcl's fixes and optimizations; exit status 1 on
                 failure, 2 for a bad command line

fixes for vcl 1.4beta7's defects (--mode=oxide enables them all):
  --fix=<names>  enable the named fixes, separated by commas; may be repeated
  --fix=all      enable every fix
                 imm: rewrite or reject immediates that do not fit their field
                 alias: keep loads and stores in order when their addresses
                 are provably equal, even through different base registers
                 clip: accept CLIPW without in_hw_clip when nothing reads the
                 undeclared clip history
                 end: keep the [E] bit and its delay slot on every exit and
                 --cont, which vcl's final compression can delete
                 size: warn about programs larger than VU1 micro memory
                 operands: accept memory operands like 0(p) in ilw and isw,
                 which vcl rejects for being short

optimizations (--mode=oxide only, which runs them all by default):
  --opt=<names>  run only the named optimizations, separated by commas; may
                 be repeated (none has a name yet)
  --opt=all      run every optimization
  --opt=none     run no optimization

diagnostics (file(line): severity: message, with the source line and a fix):
  -q             quiet mode: prints only warnings and errors
  --warnings-as-errors
                 fail the run when it prints a warning
  -h, --help     print this help
  -v, --version  print the version

accepted for compatibility, without effect:
  -t<seconds>    optimizer time limit, ignored; this optimizer has none
  -S             staggered memory access in loops, ignored; prints a notice
  -D             register dumps during external allocation, ignored; does nothing
  -Q             undocumented in the original vcl, ignored; does nothing
  -p             Microsoft-style errors, ignored: they are the only style
  -a             undocumented in the original vcl, ignored; prints a notice
  -P             deprecated and ignored; prints a warning (was prune disabled)
  -Z             deprecated and ignored; prints a warning (was disable immediate fixups)
